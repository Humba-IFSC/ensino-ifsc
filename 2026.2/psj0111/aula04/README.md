## 📋 Roteiro Orientador do Seminário das Metodologias

As equipes devem estruturar seus slides e apresentações abordando os seguintes itens obrigatórios:

1. **Definições Teóricas:** Conceituação fundamentada nos autores clássicos e contemporâneos de referência na metodologia.
2. **Procedimentos Operacionais:** Etapas sistemáticas no tratamento, coleta e análise dos dados.
3. **Cuidados do Pesquisador:** Recomendações e atenções éticas/metodológicas específicas ao aplicar o método.
4. **Potencial de Análise:** O que o método permite investigar e quais os limites de suas conclusões.
5. **Estudo de Caso Prático / Tese da CAPES:** Seleção de uma pesquisa exemplar (preferencialmente tese disponível no [Banco de Teses da CAPES](https://catalogodeteses.capes.gov.br/)) aplicando as técnicas de busca acadêmica.
6. **Mobilização no TCC:** Descrição de como a metodologia pode ser aplicada no projeto de pesquisa individual dos acadêmicos.
7. **Outras Aplicações:** Lista de problemas de pesquisa relevantes para os quais a metodologia se aplica.
8. **Referências Bibliográficas:** Indicação das fontes utilizadas e leituras sugeridas para aprofundamento.
